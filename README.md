# JSBSim Flight simulation

This repository contains flight simulation models based on JSBSim aircraft.

Aircrafts:
- A4 Skyhawk

Systems:
- Pitch Stability Augmentation System (SAS)

Tests:
- Elevator doublet command

Original project:
https://github.com/JSBSim-Team/jsbsim

JSBSim is an open-source Flight Dynamics Model (FDM) used for aircraft simulation.
